术语表、外部集合与译后校正

手动规则每行一条：源术语 = 标准译法。可在标准译法后用 | 写出需要纠正的旧译法，例如： case-control study = 病例对照研究 | 病例控制研究。 旧版 => 仍可读取，但保存、导入和导出统一使用 =。以 # 开头的行视为注释。

可导入 UTF-8 的 TXT、CSV、TSV 和 JSON。CSV/TSV 推荐列名： source、target、aliases； 没有表头时按前两列作为源术语和标准译法。Excel 文件请先另存为 UTF-8 CSV。可一次选择多个文件，并选择合并或替换当前术语表。

大模型和 Qwen-MT 会在提示词中接收命中的术语规则；所有服务都会在译后 将标题中仍保留的源术语及列出的错误译法替换为标准译法。导入文件中的 同源术语会覆盖较早规则。外部术语集合可能包含不适合当前学科或语境的 译法，建议先审查并用少量文献测试。

PDF2zh Next 全文翻译术语桥接

启用后，本插件只在运行时包装 PDF2zh 的“翻译 PDF”入口：翻译开始前， 将当前启用的标题术语表导出为 BabelDOC/PDF2zh Next 使用的 CSV，并更新 PDF2zh Server 的 config/config.toml。不会修改、替换或重新打包 PDF2zh 插件文件。

可以选择包含 server.py 的 server 文件夹，也可以选择其项目根目录。 首次同步会保存 config.toml.ztt-backup 和桥接状态文件；恢复操作只移除 本插件管理的术语路径，并尽量保留 PDF2zh 后续产生的其他配置。

当前仅支持 PDF2zh 的 pdf2zh_next 引擎。重新翻译同一篇 PDF 时， 必须绕过旧翻译缓存，否则可能直接返回术语表启用前的错误译文。测试固定术语时， 建议同时勾选“关闭 PDF2zh 自动术语提取”和“强制忽略旧翻译缓存”。 同步失败不会阻断 PDF2zh 原来的翻译流程。

自动翻译新导入文献

默认关闭。启用后，Zotero 新增普通文献条目时会自动加入翻译队列， 包括浏览器连接器、RIS/BibTeX 导入、通过 DOI/PMID 添加、PDF 元数据识别， 以及同步到本机的新条目。短时间内新增的条目会合并处理，不逐篇弹出确认框。

自动翻译只处理启用后新增的普通文献，仍会跳过中文标题、已有译题、 空标题、附件、笔记、批注和不可编辑条目。远程服务可能产生费用或消耗 免费额度；启用前请先完成服务配置，并用少量文献测试。

完成通知

完成提示使用 Zotero 右下角的无声、非模态通知，不再调用会触发 Windows 系统提示音的完成弹窗。关闭此开关后，翻译结束时不显示完成窗口； 配置错误和整库翻译前的确认框仍会显示。

批量处理

MyMemory 和 Ollama 固定单并发；其他服务使用设定的并发数。 整库翻译前会显示实际请求数量和服务费用提示。

数据与安全

译题保存在 Extra： ZoteroTitleTranslation: 译题。 中文原标题直接显示，不重复写入。

API Key 仅保存在当前设备的 Zotero 本地配置中，不会发送给本项目作者， 但当前版本未对本地保存的密钥进行额外加密。请勿在公共或多人共用设备中 保存高权限密钥。除本机 Ollama 和本机 LibreTranslate 外，远程服务都会 接收待翻译标题。
