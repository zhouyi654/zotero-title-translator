# 导入后自动翻译

## 功能概述

0.3.4 新增“导入文献后自动翻译标题”功能。该功能默认关闭，用户必须在设置中主动启用。

插件通过 Zotero Notifier 监听 `item` 类型的 `add` 事件。当 Zotero 创建新条目时，插件将条目 ID 加入待处理队列。

## 开启方法

1. 打开 Zotero 设置；
2. 进入“标题翻译”；
3. 找到“自动翻译新导入文献”；
4. 勾选“导入文献后自动翻译标题”；
5. 设置“导入后等待时间”。

默认等待时间为 3 秒，可设置为 1–30 秒。

## 可能触发的来源

- Zotero Connector；
- RIS 导入；
- BibTeX 导入；
- CSL JSON 导入；
- DOI、PMID、ISBN 添加；
- PDF 元数据识别后创建父条目；
- 同步到本机的新文献；
- 手动新建普通文献条目；
- 其他触发 Zotero 条目新增事件的操作。

## 队列与合并

连续导入多篇文献时，插件不会立即为每篇条目分别启动请求。

流程：

1. 新条目进入待处理集合；
2. 等待指定秒数；
3. 等待期间若继续新增条目，重新计算等待时间；
4. 将累计的条目合并成一个批次；
5. 加载条目并执行普通筛选规则；
6. 调用当前翻译服务。

这样可以减少重复任务和通知。

## 筛选规则

自动翻译跳过：

- 非普通文献条目；
- 附件；
- 笔记；
- 批注；
- 已删除条目；
- 不可编辑条目；
- 空标题；
- 主要为中文的标题；
- 已经保存译题的条目。

## 与手动翻译的区别

| 行为 | 手动分类/整库翻译 | 自动翻译 |
|---|---|---|
| 是否显示开始确认 | 是 | 否 |
| 是否显示费用提示 | 开始前显示 | 不逐批显示 |
| 是否处理已有条目 | 用户主动选择 | 只处理启用后的新增条目 |
| 是否覆盖已有译题 | 默认不覆盖 | 不覆盖 |
| 是否遵守限流与重试 | 是 | 是 |
| 是否阻止文献导入 | 否 | 否 |

## 服务配置缺失

若自动翻译开启，但当前服务配置不完整：

- 不调用翻译接口；
- 不阻止 Zotero 导入；
- 写入 Debug Log；
- 显示一次无声提示；
- 用户完成配置后，后续新增文献可正常翻译。

当前批次不会无限保留。配置完成后，可手动翻译此前跳过的文献。

## 与同步的关系

Zotero 同步到本机的新普通条目也可能触发新增事件。因此启用自动翻译后，从其他设备同步的新文献可能被自动翻译。

若不希望同步条目触发远程请求，应关闭自动翻译。

## 费用和隐私

自动翻译不会逐批询问确认。使用远程服务时：

- 每次新增外文文献都可能产生 API 请求；
- 可能消耗免费额度或产生费用；
- 标题会发送给当前服务商。

建议：

- 使用有额度上限的 API Key；
- 先测试少量文献；
- 大规模导入前临时关闭自动翻译；
- 大规模导入完成后按分类手动翻译；
- 对隐私敏感的项目使用本机 Ollama 或本机 LibreTranslate。

## 大规模导入建议

导入数百或数千篇文献时，推荐：

1. 先关闭自动翻译；
2. 完成导入和元数据整理；
3. 按分类分批翻译；
4. 查看服务商限流和余额；
5. 确认失败条目后再次运行。

这样比在导入过程中持续调用远程 API 更容易控制费用和错误。
