# 故障排查

## 插件安装失败或提示不兼容

检查：

- Zotero 是否为 9.0.x；
- 文件是否为 `.xpi`；
- 是否误选了源码 ZIP；
- XPI 是否被浏览器重命名；
- 是否仍安装旧测试版。

## 看不到“标题（中文）”列

1. 右键条目列表表头；
2. 勾选“标题（中文）”；
3. 重启 Zotero；
4. 检查插件是否启用。

## 右键分类没有翻译菜单

- 升级到 0.3.3 或更高版本；
- 完全退出并重新启动 Zotero；
- 确认右键的是实际分类或文献库根节点；
- 可使用顶部工具菜单作为备用入口。

## 分类翻译扫描了整个文献库

这是 0.3.2 及更早版本的已知问题。升级到 0.3.3 或更高版本。

## 自动翻译没有执行

检查：

1. “导入文献后自动翻译标题”是否开启；
2. 当前服务配置是否完整；
3. 新增的是普通文献还是单独附件；
4. 标题是否主要为中文；
5. 条目是否已有译题；
6. 是否等待了设置中的延迟时间；
7. 是否正在执行另一个批量翻译任务；
8. Zotero Debug Log 中是否有 API 错误。

## HTTP 401 / 403

通常与鉴权有关：

- API Key 错误；
- API Key 失效；
- Region 不匹配；
- 模型无访问权限；
- 项目或服务未启用；
- 请求来源限制阻止 Zotero。

## HTTP 404

可能原因：

- Base URL 错误；
- 模型名称不存在；
- 推理接入点 ID 错误；
- 服务商接口路径发生变化；
- 兼容接口不支持 `/chat/completions`。

## HTTP 429

通常是限流或配额：

- RPM 超限；
- TPM 超限；
- 突发请求过多；
- 账户共享配额用尽；
- 免费额度或余额不足。

处理：

- 等待后重试；
- 降低并发；
- 分批翻译；
- 检查服务商控制台；
- 使用不同模型或提高配额。

Qwen-MT 已内置节流和自动重试，但不能突破绝对配额。

## HTTP 500 / 502 / 503 / 504

通常是服务端临时故障或网关超时。稍后重试，或检查服务状态。

## 翻译返回解释而不是标题

大模型可能不完全遵守提示词。可尝试：

- 使用 Qwen-MT 或传统机器翻译；
- 更换模型；
- 关闭思考模式；
- 使用“重新翻译标题”；
- 报告模型和完整脱敏响应。

## 中文标题被重新翻译

检查“跳过中文标题”是否开启。中文比例较低的中英混合标题可能不会被识别为主要中文。

## 译题没有保存

检查：

- 条目是否可编辑；
- 是否为群组文库只读条目；
- Zotero 是否正在同步；
- `Extra` 是否存在格式异常；
- Debug Log 是否有 `saveTx()` 错误。

## 如何提供调试信息

提交 Issue 时提供：

- 插件版本；
- Zotero 版本；
- 操作系统；
- 当前翻译服务；
- 操作步骤；
- 脱敏后的错误信息；
- 是否单篇、分类、整库或自动翻译。

不要提供：

- API Key；
- 私人文献标题；
- Zotero 账号凭据；
- 完整 Zotero profile；
- 未脱敏日志。


## PDF2zh 术语桥接未生效

检查：

1. PDF2zh 插件是否已启用；
2. PDF2zh 翻译引擎是否为 `pdf2zh_next`；
3. 本插件术语表是否启用且非空；
4. 选择的文件夹中是否存在 `config/config.toml`；
5. 当前用户是否有写入该文件夹的权限；
6. “检测连接与配置”是否显示翻译入口已安装；
7. 生成的 `zotero-title-translator-glossary.csv` 是否存在。

桥接同步失败不会阻止 PDF2zh 继续翻译，因此应同时查看 Zotero Debug Log 中的 `[Zotero Title Translator]` 记录。
