# 术语表、外部集合与手动修改译题

## 手动修改单个译题

1. 在 Zotero 条目列表中只选择一个普通文献条目；
2. 右键选择“编辑标题译文…”；
3. 对话框显示原标题，并预填当前译题；
4. 修改后确认保存；
5. 输入留空并确认，可清除现有译题。

修改只影响 `Extra` 中的：

```text
titleTranslation: 中文译题
```

不会改动原始 `title` 字段，也不会删除 `Extra` 中的 DOI、PMID、Citation Key 等其他内容。

## 开启术语表

进入：

```text
Zotero 设置 → 标题翻译 → 术语表、外部集合与译后校正
```

勾选“启用自定义术语表”。

## 基本格式

0.3.6 起使用单个等号：

```text
源术语 = 标准译法
```

示例：

```text
cholera = 霍乱
case-control study = 病例对照研究
airway organoid = 气道类器官
```

旧版 `=>` 仍可读取，但插件保存和导出时统一写成 `=`。

匹配不区分英文字母大小写。拉丁字母术语按独立词或短语匹配，降低部分字符串误命中的风险。

## 纠正常见错误译法

在标准译法后用 `|` 写出需要替换的错误译法：

```text
case-control study = 病例对照研究 | 病例控制研究 | 个案对照研究
```

只有当原标题中出现左侧源术语时，右侧校正规则才会应用，避免无关标题被全局替换。

## 导入外部术语集合

设置页提供：

```text
导入一个或多个术语文件…
```

支持：

- TXT / `.terms` / `.glossary`
- CSV
- TSV
- JSON

可一次选择多个文件，并选择合并或替换。重复源术语以后导入的规则为准。

完整格式说明见 [`TERMINOLOGY_IMPORT.md`](TERMINOLOGY_IMPORT.md)。

## 导出与模板

设置页还提供：

- “导出当前术语表…”：可导出 TXT、CSV、TSV 或 JSON；
- “保存 CSV 模板…”：生成可直接在 Excel 中编辑的模板。

## 注释与无效行

以 `#` 开头的行不会处理：

```text
# 流行病学术语
case-control study = 病例对照研究
```

缺少 `=`、源术语为空或标准译法为空的行会被忽略。

## 不同服务商的行为

### 大模型、Ollama 和 Qwen-MT

命中的术语会写入翻译指令，要求模型使用指定译法。返回后仍会执行译后校正。

### Google、DeepL、Microsoft、MyMemory 和 LibreTranslate

当前版本不调用服务商各自的专用 glossary API。插件会在返回译文后：

- 替换仍未翻译的源术语；
- 替换规则中使用 `|` 明确列出的错误译法。

如果服务返回了未列出的同义误译，插件无法可靠推断，应手动修改译题，并把该错误译法补到规则中。

## 建议

- 只收录确实需要固定译法的专业术语；
- 源术语尽量使用完整短语；
- 外部术语集合导入后先人工抽查；
- 先用少量标题验证；
- 修改术语表不会自动重译已有译题，需要执行“重新翻译标题”。
