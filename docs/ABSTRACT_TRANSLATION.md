# 摘要翻译与侧边栏字段同步

## 数据字段

本插件 0.3.9 使用与 Translate for Zotero 相同的 `Extra` 自定义字段：

```text
titleTranslation: 中文译题
abstractTranslation: 中文摘要译文
```

这样可以让本插件生成的译文直接显示在 Zotero 信息侧边栏对应的信息行中。

插件不会覆盖：

```text
title
abstractNote
```

因此引用、导出、元数据匹配和原文检索仍使用原始内容。

## 标题旧数据迁移

0.3.8 及更早版本使用：

```text
ZoteroTitleTranslation: 中文译题
```

0.3.9 首次启动后会扫描可编辑文献库，把只有旧字段的条目迁移为：

```text
titleTranslation: 中文译题
```

已经存在 `titleTranslation` 的条目不会被旧值覆盖。

## 手动翻译摘要

1. 选择一个或多个普通文献条目；
2. 右键；
3. 选择“翻译摘要（跳过已有译文）”。

也可以使用：

- “重新翻译摘要（覆盖已有译文）”；
- “清除摘要译文”。

以下条目会跳过：

- 没有摘要；
- 摘要主要为中文；
- 已有摘要译文且未选择覆盖；
- 附件、笔记、批注；
- 不可编辑或已删除条目。

## 自动翻译摘要

设置中的“导入后同时自动翻译摘要”默认关闭。

启用后，新导入或同步到本机的普通文献若已经包含外文摘要，会加入摘要翻译队列。
部分导入器可能先创建条目、稍后才补充摘要；可适当提高“导入后等待时间”。

## 服务选择

摘要通常比标题长得多：

- 会消耗更多 token 或字符配额；
- 更容易触发超时和 HTTP 429；
- 可能超过 MyMemory 等服务的单次长度上限；
- 本地模型需要更多内存和推理时间。

建议优先使用支持长文本的正式 API 或本地大模型，并先测试一篇摘要。

## 术语表

摘要翻译继续使用当前启用的术语表。只有在摘要原文中命中的规则会加入翻译请求，
并在返回后执行已配置的误译校正。

## 侧边栏未显示

检查 Translate for Zotero 的设置，确认已经启用：

- “标题翻译”信息行；
- “摘要翻译”信息行。

本插件不会重复注册同名信息行，以免侧边栏出现两个相同字段。
